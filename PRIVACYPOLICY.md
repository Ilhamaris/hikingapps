# Kebijakan Privasi untuk HikingApps

Terakhir diperbarui: 12 Juni 2026

## Pendahuluan

HikingApps adalah aplikasi seluler yang dirancang untuk membantu pendaki merencanakan dan melacak pendakian gunung, memperkirakan waktu pendakian, dan menyimpan riwayat pendakian. Kebijakan Privasi ini menjelaskan bagaimana HikingApps mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda.

## Informasi yang Kami Kumpulkan

HikingApps hanya mengumpulkan data yang diperlukan agar aplikasi dapat berfungsi dan tidak membagikan informasi Anda kepada pihak ketiga.

### Data Pribadi dan Penggunaan
- Berat badan dan berat tas yang dimasukkan pengguna untuk estimasi waktu pendakian.
- Pilihan gunung dan rute yang dipilih dari rute bawaan aplikasi.
- Data riwayat pendakian disimpan secara lokal di perangkat Anda, termasuk rute, tanggal, durasi, dan perkiraan waktu.

### Data Lokasi
- HikingApps dapat meminta akses ke layanan GPS/lokasi perangkat Anda ketika Anda menggunakan pelacakan rute atau melihat lokasi Anda saat ini di peta.
- Data lokasi hanya digunakan untuk pelacakan pendakian di dalam aplikasi dan panduan rute.
- Jika izin lokasi ditolak, HikingApps tidak akan mengakses lokasi Anda.

### Data Perangkat dan Penyimpanan
- Riwayat pendakian dan pengaturan aplikasi disimpan secara lokal menggunakan teknologi penyimpanan perangkat seperti SQLite dan shared preferences.
- Tile peta dapat disimpan secara lokal untuk tampilan offline jika aplikasi menggunakan cache tile.
- Aplikasi tidak mengumpulkan informasi akun, alamat email, nomor telepon, atau informasi login media sosial.

## Bagaimana Kami Menggunakan Informasi Anda

HikingApps menggunakan informasi Anda untuk tujuan berikut:
- Memperkirakan waktu pendakian menggunakan parameter pengguna dan model machine learning.
- Menampilkan rute pendakian dan informasi gunung yang dipilih.
- Menampilkan lokasi Anda saat ini di peta selama pelacakan aktif.
- Menyimpan dan menampilkan riwayat pendakian yang telah selesai di perangkat.
- Memuat tile peta dari OpenStreetMap untuk rendering rute.

## Penyimpanan dan Retensi Data

- HikingApps menyimpan riwayat pendakian dan parameter input Anda secara lokal di perangkat.
- Data disimpan sampai Anda menghapusnya secara manual atau mencopot pemasangan aplikasi.
- Aplikasi tidak secara otomatis mengirim atau mencadangkan data pribadi Anda ke server jarak jauh.

## Izin

HikingApps dapat meminta izin berikut dari perangkat Anda:
- Izin lokasi: diperlukan hanya untuk menampilkan dan melacak lokasi Anda secara real-time di peta dan untuk pelacakan rute.

Aplikasi tidak meminta akses ke kamera, kontak, mikrofon, pesan, atau data pribadi perangkat lain selain lokasi.

## Layanan Pihak Ketiga

HikingApps menggunakan komponen perangkat lunak pihak ketiga berikut:
- Layanan tile OpenStreetMap untuk rendering peta.
- TensorFlow Lite untuk inferensi machine learning di perangkat.
- Geolocator untuk akses lokasi.
- Shared Preferences / SQLite untuk penyimpanan data lokal.

HikingApps tidak menggunakan jaringan iklan, layanan analitik, atau layanan pelacakan pihak ketiga.

## Berbagi Data dan Pengungkapan

HikingApps tidak membagikan, menjual, menyewakan, atau membuat data pribadi Anda tersedia bagi pihak ketiga.

## Keamanan

HikingApps berupaya melindungi data yang disimpan di perangkat Anda dengan mengikuti praktik pengembangan aplikasi seluler standar. Namun, tidak ada metode penyimpanan elektronik yang sepenuhnya aman. Anda bertanggung jawab atas keamanan perangkat dan sistem operasi tempat aplikasi diinstal.

## Privasi Anak-anak

HikingApps tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Aplikasi tidak secara sadar mengumpulkan informasi pribadi dari anak-anak.

## Perubahan terhadap Kebijakan Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Jika kami melakukan perubahan, kami akan memperbarui tanggal di bagian atas dokumen ini.

## Kontak

Jika Anda memiliki pertanyaan atau kekhawatiran tentang Kebijakan Privasi ini, silakan hubungi pengembang melalui saluran yang sesuai yang disediakan bersama distribusi aplikasi.
